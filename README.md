# README
This POS system was custom-developed to improve kitchen workflow efficiency. It currently supports Android devices only and consists of four apps:
1. OrderSystem.apk: Used at the counter to help staff take customer orders and send order details to the database.
2. GOFA (Dine-in).apk: Used at the dine-in station to receive dine-in orders and help staff prepare them accurately.
3. GOFA (Take-out).apk: Used at the takeout station to receive takeout orders and help staff prepare them accurately.
4. Workspace.apk: Used at each workstation to show staff the quantities of items they need to prepare.
